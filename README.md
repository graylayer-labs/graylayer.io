# graylayer.io

Source for [graylayer.io](https://graylayer.io), the Graylayer Labs website. Built with Astro and Tailwind, deployed to GitHub Pages from `main`.

## Run locally

```bash
npm ci
npm run dev      # local server
npm run check    # astro check
npm run build    # production build into dist/
```
